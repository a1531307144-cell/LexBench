# 示例数据

克隆仓库后，把本目录下的两个 `.txt` 文件拖入 LexBench 窗口（或点「导入文档」选择），即可立即体验全部功能。

| 文件 | 说明 | 演示内容 |
|------|------|----------|
| `中华人民共和国民法典_婚姻家庭编节选.txt` | 《民法典》婚姻家庭编部分条文（一般规定 / 夫妻关系 / 离婚，共 32 条） | 法条切分（编/章/节层级）、法条定位（试搜「民法典 1077」）、全文检索（试搜「离婚 冷静期」） |
| `示例案例_离婚纠纷_虚构演示.txt` | **完全虚构**的离婚纠纷判决书 | 案例类文档导入、全文检索命中案例段落、AI「找案例」结合本地案例归纳 |

## 来源与版权说明

- 《民法典》为公布的法律文本，依法不适用著作权保护，条文内容以官方公布文本为准；
- 案例文件为项目编写的虚构演示文本，人物均为化名，与任何真实案件无关。
