## 1. 目标

把笔记从「能用」推到「顺手」：结构编辑、拖拽、多选、快捷键、行内格式与思维导图操作，
按主流大纲/导图工具的通行交互来做，视觉与主界面令牌保持一致。

关键原则：

- 数据仍是一棵 `OutlineNode` 树，500ms 防抖整树 JSON 落库，卸载强制冲刷；
- 历史笔记零迁移：新增字段全部可选，读取时缺省即普通正文行；
- 不引入新的原生依赖；富文本用 `contenteditable` + 白名单消毒；
- 对外文案与代码注释不点名任何第三方产品，统一用「主流大纲工具」表述。

## 2. 数据模型

`OutlineNode` 在原有 `id / text / children / fold / ref / image` 基础上增加：

| 字段 | 语义 | 兼容策略 |
|---|---|---|
| `html` | 行内富文本（消毒后的 HTML） | 无格式时不存；旧数据缺省 |
| `note` | 行下方备注（纯文本） | 旧数据缺省 |
| `heading` | `1/2/3` 标题级别 | 缺省为正文 |
| `task` | `1=待办 / 2=完成` | 缺省为普通行 |
| `images` | 多图文件名列表 | 旧 `image` 仍兼容，读为单图 |

读入统一走 `normalizeOutlineTree`：补 id/text/children、修重复 id、旧 `image` 补 `images`、
无实际格式的 `html` 丢弃。导出 Markdown 时富文本降级为行内 Markdown，备注导出为引用行，
待办导出为 `[x]/[ ]`；Word 导出备注为灰色斜体缩进行。

## 3. 大纲编辑器

### 3.1 渲染结构

- 居中页面（最大宽 872px），标题 26px/500，正文 16px/1.6；
- 每行：缩进导轨（28px/级）→ 折叠钮 → 圆点（引用行换 📖）→ 内容区；
- 行悬停出现「＋ 新建子节点 / ⋯ 更多」；圆点悬停出现圆形底；
- 正文虚线以上：任务复选框、标题级别、引用行衬线体、备注行（左侧细线）；
- 节点贴图：多图缩略、悬停删除、点击大图预览。

### 3.2 结构与键盘

| 操作 | 键位 |
|---|---|
| 新建同级 / 按光标拆行 | `Enter` |
| 新建子级 / 缩进 | `Tab` |
| 反缩进 | `Shift+Tab` |
| 行首退格：空行先反缩进，再并入上一可视行 | `Backspace` |
| 上移 / 下移当前行（整棵子树） | `Ctrl+Shift+↑/↓` |
| 添加 / 编辑备注 | 行菜单 |
| 标题 1/2/3 / 正文 | `Alt+1/2/3/4` |
| 按层级折叠 | `Ctrl+Alt+1/2/3` |
| 全部折叠 | `Ctrl+Alt+Shift+.` |
| 进入子级 / 退回上一层 | `Ctrl+]` / `Ctrl+[` |
| 待办 / 完成切换 | `Ctrl+Shift+L` / `Ctrl+Shift+K` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`、`Ctrl+Shift+Z` |
| 结构全选 / 扩展选择 | `Ctrl+A` / `Shift+↑↓` |
| 复制 / 剪切 / 粘贴 / 复制节点 | `Ctrl+C/X/V/D` |

行为要点：

- 回车在「有展开子级」的父行上会把光标落到首个子节点；
- 行首 Backspace 并入上一「可视行」（可能是父行），子树跟随；引用元数据在目标行无引用时保留；
- 撤销/重做是整树快照（文字输入 700ms 汇总一次），不依赖浏览器原生 contenteditable undo。

### 3.3 选择与拖拽

- 点圆点 / 行空白 = 选中；`Ctrl+点击` 切换；`Shift+点击` 区间选择；
- 点进文字只移动光标，不点亮整行（与主流大纲工具一致）；进入编辑即结束结构选择，编辑中的行（含缩进列）不显示悬停/选中底色；标题聚焦只留光标、不加背景描边；
- **触控板适配**：双指捏合（Ctrl+滚轮）缩放页面（0.6–2.0），`Ctrl+=/-/0` 同效；缩放时标题栏显示百分比可点重置；
  页面左右留 100px 可平移空间，双指可上下左右滑动；
- 圆点按下拖动：垂直三分区决定「前 / 子级 / 后」，拖动幽灵显示数量；落点显示缩进对齐线，
  子级落点高亮目标行；多选时整块搬，禁止拖进自己的子树。

### 3.4 行内格式

- 选中文字出现白色浮动工具栏：B / I / U / S / 行内代码 / 高亮色 / 文字色 / 清除格式；
- `Ctrl+B/I/U` 切换，`Ctrl+Shift+B/I/U` 同级批量，`Ctrl+Enter` 删除线；
- 使用 Chromium `execCommand`（`styleWithCSS`）生成 `<span style>`，存储前经 DOMPurify 白名单消毒；
- 输入 Markdown 快捷语法：`# ` / `## ` / `### ` 转标题，`[ ] ` / `[x] ` 转待办。

## 4. 思维导图

- 与大纲共用同一棵树；切换视图前强制落库；
- 顶层分支**智能左右分侧**：第一个分支留右侧作主阅读方向，其余按「折叠后叶子数」权重贪心分到较轻一侧；
  两个以上分支时保证两侧都有节点；根节点新增子主题优先放较轻侧；节点白卡、圆角、细边、轻阴影，选中蓝边 + 柔光；
- **纯白画布** + 中性灰**直角肘形连线**（拐角仅 2px 轻微弯曲，分叉处不画弧线，像组织架构图）；折叠钮为小白圆；节点光标为可拖拽样式；
- 节点间距加大（横向 64 / 纵向 26），节点圆角 22px、边框更轻，避免方框堆叠感；
- 节点圆角卡片可**拖动改挂载**：落在节点中部 = 成为子级；落在上/下缘 = 前/后同级；
  拖到节点附近 90px 空白处按最近邻兜底；拖动幽灵 + 落点线/高亮；禁止拖进自己的子树；
- **不设底部常驻工具条**：右上角一个小圆形菜单入口，内含新建子主题 / 同级 / 编辑 / 备注 /
  待办 / 图片 / 复制 / 全部展开折叠 / 适应画布 / 删除；右键菜单保留同一组动作；
- **弹性画布**：画布四周额外留白（`hmargin 640 / vmargin 480`），即使空白/小图也能四向拖动；
  打开时视口居中；空白处 `grab`、拖动 `grabbing` 光标（低调的抓手提示）；
- **触控板**：双指捏合 = ctrl+wheel，jsMind `zoom.mask_key: 4096`（修饰键掩码，不是 keyCode）；双指滑动 =
  普通 wheel，由组件手动 `e_panel.scrollLeft/Top` 平移；
- 右下缩放控件：缩小 / 百分比 / 放大 / 适应画布；`Ctrl+=/-/0` 同效；
- 键位：`Tab` 子主题、`Enter` 同级、`Shift+Tab` 前插同级、`Space/F2` 编辑、
  `Delete` 删除、方向键导航、`Ctrl+D` 复制、`Ctrl+Z/Y` 交给整树撤销；
- 节点装饰：待办方框 / 完成划线、备注角标、**节点内图片缩略图**（自定义节点渲染；首图显示、多图角标 `+N`）；
  图片只插入当前选中/正在编辑的主题（键入时 Ctrl+V 也落当前主题），**不自动新建方框**；中心主题不能直接放图，会提示先选子主题；
- 双击 / 空格编辑文本；**编辑框随输入自动加宽**；编辑结果回写大纲（纯文本覆盖该行 `text`，
  原行内格式按保守策略丢弃）；编辑中心主题等于修改笔记标题。

## 5. 已知边界（本版不做）

- 表格、公式、跨文档提及、概要括号、关系线等进阶块级能力；
- 导图多选 / 主题与结构模板 / 大纲与导图的自由布局；
- 跨节点文本划选（每个节点是独立 contenteditable；节点级多选已覆盖结构操作）；
- 备注与正文的富文本格式（备注为纯文本，正文支持行内格式）。
