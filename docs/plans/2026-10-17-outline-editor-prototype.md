# 大纲编辑器交互原型稿（2026-10-17 用户过目版，阶段2动工依据）

> 用户已确认的定稿。与主设计稿（2026-10-15-reading-notes-redesign-design.md §3.5/§9-2）配套，
> 冲突时以两稿合并语义为准。**知识产权红线（用户 2026-10-17）**：只借鉴业界通用交互概念，
> 不复制任何第三方产品的代码/文案/美术；公开文档与发布说明不出现任何竞品名称。

## 0. 定稿决策清单（用户拍板）

- 节点折叠：**第一版就要**；节点级备注：**不做**；
- 键位：采用**业界大纲工具通用惯例**（含 Backspace 空行=反缩进、到底=并入上一行）；
- 树**拍平成行列表**渲染（业界通用渲染手法）；
- 读→写**只做「复制引用」**（不做「发送到笔记」，文档库保持阅读纯粹性）；
- 写→读**单击不跳**；**逃生门保留**：引用节点右键「在文档库打开来源」；
- **续读契约必须做好**（做好则笔记不需要浮窗），详见 §3。

## 1. 数据模型

- 迁移 **017**（下一号）：`outlines` 表 —— id / title / tree(JSON) / created_at / updated_at；
- 树节点：`{ id, text, children[], fold? }`（无节点级备注；fold=折叠态布尔）；
- 引用节点：行文本 = `《法规名》第X条` 引用语法 + 元数据 `ref: { docId, articleId }`（右键逃生门与插入浮层复用）；
- 自动保存：防抖 500ms **整树 JSON 落库**；星标：`articles.starred`（迁移同批或 018）。

- 左列（240px）：搜索 + 列表（更新时间序）+ 星标法条入口；右区编辑器；「⋯」= 重命名/导出 md|docx/删除；
- 一行解剖：`▾ 折叠钮(有子节点才显示) | ● 圆点(拖动把手) | 行文本(纯文本可换行)`；
- 引用节点：圆点位置换 📖，文本用衬线体 `--lb-serif`；右键菜单 = 剪切/复制/删除/粘贴 + 在文档库打开来源。

## 3. 键位表（业界大纲工具通用惯例，零学习成本）

| 键 | 行为 |
|---|---|
| Enter | 当前行下新建同级行 |
| Tab / Shift+Tab | 降一级 / 升一级（子树整体跟随；仅行首生效） |
| Backspace（行首空行） | 先反缩进一级；已在顶级 → 并入上一行末尾 |
| Backspace（行首非空） | 并入上一行 |
| ↑ / ↓ | 行间移动（落点按视觉列） |
| 点击 (▸) / 双击折叠钮 | 折叠/展开子树（折叠行显示子节点计数） |
| 圆点拖动 | 移动行（含子树），插入位置画蓝色指示线（复用拖动排序配方） |
| / 或 @ 或工具条「插入」 | 打开插入引用浮层 |

## 4. 插入引用浮层（定稿「＋连加」）

浮层内搜文档库 → 建议列表每条右侧 [＋] → 点 ＋ 插到光标处，**浮层不关可连加**；
插入 = 引用节点（《法规》第X条）+ 条文正文为**子节点**（折叠即隐、嫌长即删）。

## 5. 续读契约（§3.5 摘要，阶段2 顺手实现）

- 离开阅读（切笔记）时**强制冲刷进度落盘**（StatuteReadingView/ReadingView 卸载钩子补 flush，现防抖 0.5s 会丢最后半秒）；
- 返回文档库：离开时在读 → **静默重开该文档恢复位置**（不弹横幅）；停在首页 → 回首页；
- 顶栏搜索直达自动切到文档库方向；续读取最近一次阅读；期间文档被删 → 回首页 + 提示。

## 6. 明确不做（本期）

节点级备注、虚拟滚动（千行内直渲）、行内富文本、笔记独立浮窗（续读契约成立后再说）。

## 7. 实施顺序

1. 数据层：迁移017 outlines（+星标列）+ 主进程 CRUD IPC + preload；
2. 编辑器：拍平行渲染 + 键位/折叠/拖动 + 自动保存；
3. 插入浮层 + 阅读区「复制引用」右键项 + 引用节点「打开来源」；
4. 笔记列表/搜索/星标入口；
5. 续读契约（进度 flush + 静默恢复）；
6. 六套自测扩展（新套 selftest-notes 或并入 core）+ 全闸门（tsc/vitest/build/自测）。
