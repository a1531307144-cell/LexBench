LexBench · 法研台 v__VERSION__ —— 使用说明

【启动】
  双击 LexBench.exe，稍候 2-5 秒会打开软件窗口。

【首次运行的安全提示】
  Windows 可能弹出"已保护你的电脑"蓝色窗口（因为本软件没有购买
  微软的代码签名证书，这是所有个人开源软件的共同待遇）。
  处理方法：点"更多信息" → 点"仍要运行"。
  软件所有代码公开可查：github.com/a1531307144-cell/LexBench

【你的数据在哪】
  全部保存在本文件夹的 data\ 子目录里（文档、笔记、数据库）。
  换电脑：整个文件夹拷走即可。卸载：直接删除文件夹。

【AI 功能（可选）】
  软件内"设置"里填入你自己的 AI 接口（DeepSeek / 通义 / Kimi /
  OpenAI 等任一家的接口地址 + 密钥）。不配置也能用其他全部功能，
  AI 密钥只存在你自己电脑上。

【演示数据】
  软件启动后是空的。可在 GitHub 仓库的 samples\ 文件夹下载示例
  文档（民法典节选等），拖进软件窗口即可体验全部功能。

【常见问题】
  - 双击没反应/闪退：先解压压缩包再运行（不要在压缩包里直接双击）
  - 窗口打不开：安装微软 WebView2 运行时（软件会给出下载地址）
